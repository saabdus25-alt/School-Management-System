# School Management System - Java

Console-based Java MIS project.

Features:
- Student management
- Teacher management
- Subject management
- Attendance
- Examination results
- Automatic grade calculation
- Fee management
- Student full report
- Dashboard
- Search
- OOP with multiple classes
- ArrayList collections
- Input validation and exception handling

Run:
1. Open this folder in VS Code.
2. Open Terminal.
3. Go to src:
   cd src
4. Compile:
   javac *.java
5. Run:
   java Main
